Tekken Tag Tournament 2 on Windows.

- [Setup and launcher guide](SETUP.md)
- [Changelog](CHANGELOG.md)

**This version needs a one-time manual launcher replacement.** Close TAG2 and its launcher, extract the **entire ZIP into the same folder as your existing Tag2Launcher.exe**, and keep the **launcher-update** subfolder. Run **Install-Launcher.cmd**, then open **Tag2Launcher.exe** and choose **Install update**. Keep the same installation folder to retain your account, settings and saves. Do not copy files from inside launcher-update by hand.

For a fresh installation, extract the complete ZIP to an empty folder on a local fixed **NTFS** drive and run the same installer. You need your own original game and matching Xbox 360 Title Update; the game, ISO and Title Update are not included. Both download ZIPs are stored directly in this repository.

After this one-time replacement, use the new launcher's update notice and **Install update** for subsequent updates. Compatible installed engines are patched automatically without a full rebuild or moving the game folder.

Direct3D 12 and Full readbacks remain the defaults. See the [graphics guide](SETUP.md#slow-motion-or-stutters) for settings and troubleshooting.

Report problems through [Issues](https://github.com/adageshi/tag2-pc/issues), with your version and reproduction steps. Share diagnostic ZIPs privately; do not post account credentials publicly.

Test release. Online stability, rendering and hardware performance are still being qualified. Development sources and internal input work remain private.
