# TAG2 PC

Tekken Tag Tournament 2 on Windows.

The public home of the project for news, updates and player feedback.

## Getting started

Use the latest launcher provided by the project. You will need your own original copy of the game.

## Feedback

Report problems through [GitHub Issues](https://github.com/adageshi/tag2-pc/issues). Include your launcher version and a brief description of what happened.

## Project status

In active development. Some features are still being tested.

This repository contains public project information. Development sources and internal optimizations are maintained privately.

Unofficial fan project. Not affiliated with or endorsed by Bandai Namco.
